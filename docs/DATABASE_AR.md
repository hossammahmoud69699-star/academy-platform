# مخطط قاعدة البيانات — الإصدار الأول

المخطط موجود في `supabase/migrations/0001_initial_schema.sql`.

## الجداول

- `profiles`: ملف المستخدم والدور.
- `academic_grades`: الصفوف الدراسية.
- `subjects`: المواد.
- `courses`: الكورسات.
- `course_teachers`: ربط المدرسين بالكورسات.
- `chapters`: الفصول والوحدات.
- `lectures`: المحاضرات وبيانات الفيديو والمرفقات.
- `enrollments`: اشتراكات/إتاحة الكورسات للطلاب.
- `activation_codes`: أكواد التفعيل المخزنة كتجزئة، لا كقيمة صريحة.
- `code_redemptions`: سجل استخدام الأكواد.
- `lecture_progress`: آخر تقدم ونسبة مشاهدة تقريبية.
- `watch_events`: أحداث المشاهدة.
- `exams`, `questions`, `answer_options`: بنية الامتحانات.
- `exam_attempts`, `student_answers`: المحاولات والإجابات.
- `notifications`: سجل الإشعارات.
- `audit_logs`: سجل العمليات الإدارية الحساسة.
- `devices`: الأجهزة المرتبطة بالحساب.

## ملاحظات

- هذا مخطط أولي يحتاج إلى اختبارات وسياسات RLS قبل استخدامه مع بيانات حقيقية.
- لا يحتوي المخطط على بيانات طلاب حقيقية.
- لا تخزن كلمات المرور في جداول التطبيق؛ يستخدم Supabase Auth.
- نسبة المشاهدة ليست دليلًا قطعيًا على انتباه الطالب.
