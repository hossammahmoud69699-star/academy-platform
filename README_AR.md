# منصة التعليم الإلكتروني — المرحلة الأولى

هذه الحزمة هي بداية المشروع: المعمارية، هيكل الملفات، ومخطط قاعدة البيانات الأولي.
لم يتم بعد إنشاء التطبيق الكامل أو تشغيل قاعدة البيانات؛ هذه المرحلة تحدد الأساس قبل كتابة الشيفرة التشغيلية.

## التقنية المختارة

- تطبيق الطالب Android: React Native + Expo + TypeScript.
- لوحة الإدارة: Next.js + TypeScript.
- قاعدة البيانات والمصادقة: Supabase (PostgreSQL + Auth).
- ملفات المحتوى: Supabase Storage في البداية، مع التنبيه إلى حدود الخطة المجانية.
- وظائف الخادم الحساسة: Supabase Edge Functions / PostgreSQL Row Level Security.
- مستودع المشروع: GitHub.
- البناء من الموبايل: تحرير الملفات عبر GitHub في المتصفح، وبناء Android عبر GitHub Actions لاحقًا.

## لماذا هذا الاختيار؟

هذا المسار يقلل الحاجة إلى تثبيت أدوات تطوير ثقيلة على الموبايل، ويستخدم خدمات لها خطط مجانية. الخطة المجانية لها حدود وقد تتغير؛ الفيديوهات الكبيرة أو أعداد الطلاب المرتفعة قد تتطلب خدمة مدفوعة لاحقًا. لا ترفع فيديوهات الطلاب أو بيانات حقيقية قبل إعداد الصلاحيات وسياسة الخصوصية.

## تنبيه أمني

- لا تضع مفاتيح `service_role` أو كلمات مرور في تطبيق الهاتف أو في ملفات GitHub العامة.
- يمكن استخدام المفتاح العام `anon/publishable` في العميل فقط مع تفعيل RLS وسياسات صحيحة.
- لا تجعل ملفات الفيديو عامة إذا كان الوصول إليها مدفوعًا.
- لا تعتبر ربط الجهاز ضمانًا مطلقًا لمنع مشاركة الحساب.
- لا توجد حماية تمنع كل وسائل تصوير الشاشة؛ استخدم عدة طبقات حماية.

## الخطوة التالية

بعد مراجعة المرحلة الأولى، ننتقل إلى إنشاء قاعدة البيانات وسياسات الوصول واختبارها قبل بناء واجهات التطبيق.
